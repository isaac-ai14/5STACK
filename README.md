# 🎮 5STACK

O **5STACK** é uma plataforma web desenvolvida para jogadores de **VALORANT** encontrarem parceiros de equipe (*duos* ou *squads*) com base no seu nível de habilidade e funções dentro do jogo, eliminando a aleatoriedade e o comportamento tóxico nas partidas ranqueadas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação e marcação do conteúdo.
- **CSS3**: Estilização, layout em Flexbox e efeitos visuais customizados.

---

Para rodar o projeto localmente na sua máquina, siga os passos abaixo:
